# Daily Brief

A personal, single-page dashboard that replaces watching the news. It shows
the **top 5 stories per category** for the day plus an **hourly market snapshot**
so you can see, at a glance, what's actually happening in the world.

- **News** — politics & geopolitics, finance, conflicts, science, resources.
  Sourced from authoritative outlets, ranked by source authority, recency, and
  cross-source coverage. Refreshed once a day.
- **Markets** — BTC, ETH, gold, oil, S&P 500, MSCI World, VWCE, NVDA, MSFT
  (OpenAI proxy), Palantir, Leonardo, Rheinmetall. Each asset gets a
  **bull / bear / neutral** signal from the 200-day SMA trend and 14-day RSI.
  Refreshed every hour.

The site is a buildless static project. There is no bundler, no framework, and
no backend — data files are regenerated by GitHub Actions on a schedule and
committed back to `main`, which retriggers Pages.

## Sources

**News** — Reuters, Associated Press, AFP, BBC World Service, Al Jazeera
English, Deutsche Welle, France 24, Nikkei Asia, UN News, IMF, ECB, NASA,
ESA, USGS, IEA, ACLED.

**Markets** — CoinGecko (crypto), Stooq (equities, indices, ETFs, commodities).

## How news ranking works

For each category, we collect items from a curated set of feeds, then score:

```
score = authority(source)
      * recency_decay(age_hours)         # exp(-age / 24h)
      * (1 + ln(1 + cluster_size))        # cross-source coverage
      * (1 + 0.25 * keyword_hits)         # category relevance
```

Items whose titles fuzzy-match (rapidfuzz token-set ratio ≥ 78) are merged into
a single cluster; the cluster keeps the highest-scoring representative and a
count of how many outlets reported the same story. The five highest-scoring
clusters per category make it into `data/news.json`. The single highest-scoring
cluster across **all** categories becomes the hero headline.

## How the market signal works

For each asset we pull ~1 year of daily closes, then compute:

- `SMA50`, `SMA200` — simple moving averages of close prices.
- `RSI(14)` — Wilder's relative strength index.

Classification:

| Condition                                                | Signal    |
|----------------------------------------------------------|-----------|
| `price > SMA200` **and** `40 < RSI < 70`                 | Bullish   |
| `price < SMA200` **and** `RSI < 45`                      | Bearish   |
| Anything else                                            | Neutral   |

This is a sanity check, not financial advice.


## Run locally

There is no build step. From the project root:

```bash
python3 -m http.server 8000
```

Open <http://localhost:8000>. The dashboard will load `data/*.seed.json` until
real data files exist.

To produce real data locally:

```bash
pip install -r update-scripts/requirements.txt
python update-scripts/fetch_news.py
python update-scripts/fetch_prices.py
```

## Deploy

Push to `main` and GitHub Pages will publish the site. The two scheduled
workflows commit refreshed JSON back to `main`, which re-triggers the Pages
workflow and ships the new content within a minute.

## Customization

- **Theme** — five palettes (Coral Navy, Press Room, Command Center, Midnight
  Atlas, Nordic Dusk) × dark / light. Persisted in `localStorage` under
  `db-palette` and `db-mode`.
- **Tracked assets** — edit `update-scripts/fetch_prices.py` (the `ASSETS` dict).
- **News sources / weighting** — edit `update-scripts/fetch_news.py`
  (`FEEDS`, `KEYWORDS`, `AUTHORITY`).

## Notes

- **Anthropic and OpenAI are private**: there is no public ticker for either.
  MSFT is included as a proxy for OpenAI (Microsoft holds an economic interest
  of roughly 49% in OpenAI). Any private-company indicator must be added by
  hand.
- News fetching depends on free RSS feeds. If a wire kills its public feed,
  swap it for a Google News mirror — the script already handles them.
